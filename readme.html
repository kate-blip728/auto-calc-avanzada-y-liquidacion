Auto Calc Avanzada y Liquidación 0.1.0 de prueba

Abre la calculadora con NVDA+Alt+C o desde el menú Herramientas de NVDA. Usa Tab para recorrer controles y Control+Tab para cambiar de página. En Gestos de entrada puedes cambiar el atajo.

Conserva la calculadora, operaciones avanzadas, conversores, fechas, dados, historial, liquidaciones y sonidos de Navaja. Se abre sin iniciar Navaja. Los datos se guardan en la carpeta AutoCalcAvanzadaLiquidacion de los datos de aplicación de Windows.

En Liquidaciones guardadas puedes consultar si cada registro está pendiente o confirmado en la nube. En Inventario y nube configura Google Drive o Dropbox y pulsa Sincronizar ahora. Estar conectado no confirma que se haya enviado el contenido.

La conexión necesita una aplicación OAuth configurada. Para compartir con Navaja y el móvil, usa la misma aplicación y cuenta: la carpeta appDataFolder de Google Drive es privada de cada aplicación. No se incluyen credenciales en este complemento.

Esta versión ha pasado pruebas de código y compilación. Falta validar su instalación, lectura y navegación con NVDA real y la sincronización en cuentas reales. No se ejecuta en el escritorio seguro de Windows.
